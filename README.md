# Portfolio Website

Personal portfolio for Krushnasinh Jadeja — Senior Software Engineer, Cursor Ambassador, and AI Consultant.

## Features

- Homepage with current title, products, Cursor community stats, selected client work, skills, experience, and contact.
- Public products: In-Hand Helper, Backdrop Studio, SIP Calculator, EventClaim, Router Pulse.
- Contact form via Resend.

## Tech Stack

- React & Next.js (App Router & Server Actions)
- TypeScript
- Tailwind CSS
- Motion
- React Email & Resend
- Vercel hosting
